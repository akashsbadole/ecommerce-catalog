# Product Import from Shopify & WooCommerce

## Overview
Add native integration to import products from Shopify and WooCommerce stores into the existing product management system.

## Current State Analysis
- Products are managed via `/admin/products` using `AdminProducts.tsx`
- Existing CSV import at `/api/products/import` handles file uploads
- Product schema includes: name, slug, description, price, comparePrice, wholesalePrice, minOrderQty, sku, images, categoryId, isFeatured, isActive, sortOrder, specifications, metaTitle, metaDescription, stock, lowStockThreshold
- Settings stored in `SiteSetting` model with key-value pairs
- Uses `adminFetch` wrapper for API calls
- Prisma PostgreSQL database

## Implementation Plan

### Phase 1: Database Schema (Settings Storage)
Add settings for external store integrations:

**New Settings Keys:**
- `shopify_store_url` - Store URL (e.g., mystore.myshopify.com)
- `shopify_api_key` - Admin API key
- `shopify_api_secret` - Admin API secret (encrypted)
- `shopify_last_sync` - Timestamp of last sync
- `woocommerce_store_url` - Store URL
- `woocommerce_consumer_key` - REST API consumer key
- `woocommerce_consumer_secret` - REST API secret (encrypted)
- `woocommerce_last_sync` - Timestamp of last sync

### Phase 2: Backend API Endpoints

**Create `/src/app/api/integrations/shopify/route.ts`:**
- `GET` - Test connection and fetch store info
- `POST` - Import products (with incremental pagination)
- Handle Shopify Admin API authentication (Bearer token)
- Map Shopify fields to local product schema

**Create `/src/app/api/integrations/woocommerce/route.ts`:**
- `GET` - Test connection and fetch store info
- `POST` - Import products (REST API with pagination)
- Handle WooCommerce REST API authentication (OAuth1 or HTTPS basic auth)
- Map WooCommerce fields to local product schema

**Create `/src/app/api/integrations/test-connection/route.ts`:**
- Generic endpoint to test both connections
- Returns status and store info

### Phase 3: Frontend UI Components

**Add to `AdminSettings.tsx`:**
- New "Integrations" section with tabs for Shopify/WooCommerce
- Credential input forms (hidden secrets)
- "Test Connection" button
- "Import Products" button with progress indicator
- Last sync timestamp display

**Modify `AdminProducts.tsx`:**
- Add integration import buttons next to CSV import
- Show import source in product list (optional badge)
- Add filter option to show imported products

### Phase 4: Field Mapping

**Shopify → Local Product:**
| Shopify Field | Local Field |
|---------------|-------------|
| title | name |
| handle | slug |
| body_html | description |
| vendor | sku (prefix) |
| variants[0].price | price |
| variants[0].compare_at_price | comparePrice |
| images[*].src | images (array) |
| product_type | category (create if needed) |
| published_at | isActive |
| tags | metaKeywords |

**WooCommerce → Local Product:**
| WooCommerce Field | Local Field |
|-------------------|-------------|
| name | name |
| slug | slug |
| description | description |
| regular_price | price |
| sale_price | comparePrice (or wholesalePrice) |
| images[*].src | images (array) |
| categories[*] | categoryId |
| sku | sku |
| manage_stock | stock (if enabled) |
| stock_quantity | stock |

### Phase 5: Import Logic

**Key Features:**
1. **Manual Trigger Only** - No automatic sync, user-initiated import
2. **Incremental Import**: Skip existing products by external ID stored in meta (optional toggle)
3. **Category Creation**: Auto-create categories if they don't exist
4. **Image Handling**: Keep external URLs (no download) for simplicity
5. **Error Handling**: Log errors, continue on individual failures
6. **Progress Tracking**: Return imported count and errors via toast notification

**Implementation Details:**
- Store external IDs in product metadata (e.g., `externalRef: "shopify_12345"`)
- Handle rate limiting for both APIs
- Batch processing (50-100 products per batch)
- Sync timestamp for incremental imports
